# tecstats-site
Test site for the Tecstats ad portal, served at tecstats.com.

- `index.html`: the home page, with the 300 x 250 slot.
- `ad-test/`: one slot for every size and format the portal offers, each tag
  pasted in exactly as the portal hands it out. Start at `ad-test/index.html`.
  Not linked from the home page, and every page is `noindex`.
