Every ad format on Tecstats

One slot for every size and format the Tecstats ad portal offers, spread over the pages below. Each tag is pasted in exactly as the portal hands it out.

Unsold, a banner slot shows the Advertise card. Once a test ad is approved for a slot, the ad shows instead. These pages are for testing and are not linked from the site.

  • Every banner size: twelve static banners, from 300 x 250 to 1200 x 50, each in a box of its own size.
  • Sticky banner, 728 x 90: stays at the bottom middle of the window while the page scrolls.
  • Sticky banner, 320 x 50: the same for phones.
  • Interstitial, 320 x 480: covers the page on the first click.
  • Native ads in an article: four across, in the site's own style.
  • Native exit: opens when the pointer leaves the window.
  • Native interstitial: native ads over the page on the first click.
